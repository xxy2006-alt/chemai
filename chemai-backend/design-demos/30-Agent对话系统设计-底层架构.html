§ 09记忆管理

Agent 的"记忆"分为三个层次，各由不同机制负责。消息组装顺序：档案 → 情景记忆 → 历史对话 → 当前输入。

30.09

工作记忆

情景记忆
Episodic Memory		 内存字典无硬上限单次请求内关键事件（诊断结果、考试记录）
学生档案
Student Profile		 数据库查询每生一份跨请求持久姓名、障碍类型、练习完成数

持久化机制

LangGraph Checkpointer → SQLite，服务重启不丢对话。
AsyncSqliteStore 提供跨会话键值存储（学生诊断历史 ×5、教师偏好）。

上下文裁剪衔接

每次 Agent 调用前自动裁剪。触发：>30 条 → 保留最近 6 条 + 关键词命中 → LLM 摘要。裁剪结果写回 Checkpointer。

对话重置

清空 Checkpoint 消息列表（写入空数组），清除内存中的对话元数据缓存。
如同新建对话。

§ 11错误处理

完整异常体系：基类 AgentError → 6 个子类，每个带 code + recoverable + to_sse()。safe_tool_call() 包装器确保工具异常不炸流程。

429/500/502/503 → 指数退避重试 3 次

规划失败 → 回退到单步 Plan

不可恢复异常

Persona 无权该技能 → 拒绝执行

safe_tool_call() 包装器：try → 执行工具 → 成功返回原值；except → 构造 ToolError → 返回结构化 JSON {"error":..., "code":..., "_tool_error": true}。LLM 收到结构化错误后尝试替代方案。

文本去重算法

LLM 有时逐字复述辅导工具引导内容 → 去重算法维护 4 个状态：

① 上一条工具输出文本（对比基准）
② LLM 新回复前缀累积（前缀匹配）
③ 去重决策锁（判断后不再重复判断）
④ 工具完整性标记（guidance/step 键 → 跳过 LLM 文本）

重叠 > 70% → 判定为回显 → 跳过
