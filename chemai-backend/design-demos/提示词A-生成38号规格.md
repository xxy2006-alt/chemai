# 提示词 A · 从 20 号信息架构生成 38 号前端页面设计规格

## 用法
把以下文件拖进 AI 工具作参考，然后发送下面的指令。

## 输入文件
- 20-信息架构与导航设计.md（§5 各页面组件清单与数据依赖——必须提供，这是每页组件的事实来源）
- 35-设计系统.md（组件视觉/色值/字体——组件清单里"引用设计系统"用）
- 21-页面流程与交互设计.md（可选，关键交互素材）

## 指令
请基于我提供的 20号信息架构（重点是 §5 各页面组件清单与数据依赖）和 35号设计系统，生成 38号前端页面设计规格（ChemAI 全部 14 个前端页面的集中设计规格）。

要求：
1. 每个页面按统一四部分结构写，顺序固定：① 布局分区（页面有几个区域、各自位置与尺寸）② 组件清单（每个组件 + 状态变体 + 数据来源）③ 关键交互（用户操作 → 系统响应）④ 状态处理（加载态 / 空态 / 错误态全覆盖）。
2. 组件清单 MUST 从 20 号 §5 的组件表逐项展开，禁止新增 20 号文档里没有的组件；组件视觉引用 35 号设计系统（按钮/卡片/标签/弹窗等变体）。
3. 状态处理 MUST 每页至少三态：加载态（骨架屏/占位）、空态（引导语+行动按钮）、错误态（描述+重试），结合该页实际组件写具体 UI 描述。
4. 关键交互 MUST 从 21 号流程和 35 号组件行为（按钮按压/聚焦/悬停）推导，写成"操作 → 响应"句式。
5. 14 个页面的清单：教师端 7 页（AI Agent 对话主面板 / 考试工作台四 Tab / 班级学情面板 / 学生管理 / 障碍诊断 / 答题卡 OCR 上传 / 答题卡批改）、学生端 6 页（AI 助教对话 / 练习做题 / 错题本 / 复习中心 / 个人报告与设置 / 学生登录）、家长端 2 页（家长登录 / 家长主面板三 Tab）。
6. 末尾单列一节"跨页面交互协议"：Agent SSE 事件（navigate/populate/action）→ 前端桥接存储 → 目标页自动配置状态；列出至少 4 条真实跨页数据传递场景。
7. 逐页输出，每页内部四部分结构用 Markdown 小节组织；组件清单用表格（组件 | 状态变体 | 数据来源）。
