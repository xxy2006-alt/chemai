# 提示词 B · 从产品定位生成 35 号设计系统（提案制）

## 用法
把以下文件拖进 AI 工具作参考，然后发送下面的指令。
注意：本提示词是"提案制"——AI 只出方案给人选，不直接定稿。

## 输入文件
- 05-产品愿景.md（或 PRD 的产品定位章节——品牌隐喻、目标用户、使用场景）
- 37-技术选型与工具链.md（可选，技术约束：Tailwind/antd/KaTeX+mhchem/pywebview）
- 已有界面的截图或 CSS 摘录（可选，资产提取）

## 指令
你是资深设计系统专家。请为 ChemAI（智辅化学，面向高中化学教师/学生/家长的三端 AI 教学平台）设计设计系统方案。

设计理念（必须作为一切决策的出发点）：
- 核心隐喻：Academic Catalyst（学术催化剂）——ChemAI 是化学学习的催化剂，降低学习反应的活化能，自身不消耗。
- 三根支柱：学术严谨（教学工具，传达专业与可信赖）；现代学术（冷调、干净、信息层级靠明度差）；清晰分层（AI 的声音与系统的声音必须可区分）。
- 技术约束：化学式渲染用 KaTeX + mhchem，化学式/代码需等宽字体精确对齐；前端 React + Tailwind + antd；三端（桌面教师端 / 移动学生端 / 移动家长端）。

请输出：
1. **2-3 套完整色板方案**，每套包含：主色（系统声音）+ 强调色（AI 声音）+ 页面背景/表面/层次色 + 语义色（通过/警告/阻断，浅底深字标签式）+ 每套的气质一句话说明。
2. **每套方案的论证链**：每个颜色为什么这样选——它承担什么角色、防止什么误用（例如：Teal 留给 AI 声音，防止用户分不清"这是 AI 在说话"还是"系统在命令"）。
3. **字体体系**：标题/正文/化学式代码三栈，给出字体族和理由（化学式为什么需要等宽）。
4. **圆角与阴影体系**：按钮/卡片/弹窗/标签圆角档位；阴影层级。
5. **方案对比表**：2-3 套方案并列，标注各自气质、适配场景（严肃校方采购 vs 学生亲和 vs 平衡）。
6. **明确不做的事**：不直接定稿；等选定方案后再细化完整色板。

约束：色值数量控制在可维护范围（主色 2-3 + 语义色 3 + 中性色若干）；语义色必须满足"浅底深字标签"可读性（对比度合格）。
