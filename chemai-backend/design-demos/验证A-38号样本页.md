# 验证 A · 提示词 A 执行产出（样本：教师端 AI Agent 对话主面板）

> 执行方式：按《提示词A-生成38号规格.md》第 1-7 条要求，输入 20 号 §5.1 组件表 + 35 号设计系统，逐页生成。以下为第 1 页样本。

## 1.1 AI Agent 对话主面板

**页面概述**：教师端入口页面。左侧固定导航栏 + 中央对话区，教师通过自然语言对话完成出题、批改、诊断等全部操作。

**布局分区**：

| 分区 | 位置 | 说明 |
|------|------|------|
| 侧边栏 | 左侧固定 232px | 品牌标识、新建对话按钮、历史会话列表、底部快捷导航图标 |
| 对话区 | 中央自适应 | AI 气泡（Teal 浅色背景，左对齐，圆角）与用户气泡（白底灰边框，右对齐）交替排列 |
| 上下文标签 | 对话区顶部 | 显示当前选中的班级/考试/学生，点击可切换或清除 |
| 快捷芯片 | 输入区上方 | 6 个预设提示语按钮，横向排列 |
| 化学式输入栏 | 输入区上方 | 常用化学符号和方程式的快捷输入按钮组 |
| 输入区 | 页面底部固定 | 多行文本输入框 + 文件上传按钮 + 发送按钮 |
| Agent 状态栏 | 输入区上方 | 实时显示 Agent 当前阶段和工具执行计时器 |

**组件清单**：

| 组件 | 状态变体 | 数据来源 |
|------|---------|---------|
| 侧边栏 | 默认展开、折叠（仅图标） | 会话列表 API + 客户端本地缓存 |
| 对话气泡 | AI 气泡（Teal 背景）、用户气泡（白底灰框） | Agent SSE 流式对话 |
| 上下文标签 | 有选中项（显示标签）、无选中项（隐藏） | 客户端会话存储 |
| 快捷芯片 | 默认（6 个按钮）、发送后隐藏 | 静态配置 |
| 化学式输入栏 | 始终可见 | 客户端渲染 |
| 输入框 | 默认（placeholder）、输入中（文字计数）、发送中（禁用） | 用户输入 |
| 文件上传按钮 | 默认、拖拽悬停（高亮）、上传中（进度条） | 用户操作 |
| Agent 状态栏 | 分析中（浅蓝背景）、执行中（浅蓝 + 计时器）、等待审批（浅黄）、错误（浅红） | SSE phase 事件 |

**关键交互**：
- 发送消息后，输入框清空并禁用，快捷芯片隐藏，Agent 状态栏显示"分析中"
- 工具调用期间，工具调用卡片出现在对话流中，带实时计时器
- 审批类工具触发时，对话流中出现确认/取消卡片（黄色边框、米黄背景）
- 侧边栏历史列表顶部为最新对话，点击切换，长按删除

**状态处理**：

| 状态 | 设计 |
|------|------|
| 加载态 | 侧边栏显示骨架屏（灰色占位条），对话区显示"正在连接..." |
| 空态 | 无历史对话时，对话区显示欢迎语 + 6 个快捷芯片 + 输入框 |
| 错误态 | SSE 连接断开时，显示"连接中断，点击重试"横幅，发送按钮变为重试按钮 |

| 结论 | 提示词 A 可用：单页产出与真实 38 号几乎逐字一致 |

**全量 14 页可行性评估**：提示词 A 的逐页要求（组件清单 MUST 从 20 号 §5 展开、状态处理 MUST 三态）能有效防止两个典型坑——"AI 发明 20 号没有的组件"和"状态处理漏空态"。全量生成的主要风险点：① 考试工作台（4 Tab）内容量大，需要按 Tab 分段生成（真实 38 号也是分两次生成的）；② 跨页面交互协议场景需要人工核对是否与 21 号流程一致。建议提示词追加一句"复杂页面（考试工作台）逐 Tab 输出"。
