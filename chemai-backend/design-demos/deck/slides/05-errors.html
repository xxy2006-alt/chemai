§ 11 · 错误处理

错误不是 bug，是可恢复信号

完整异常体系：基类 AgentError → 6 子类，每个带 code + recoverable + to_sse()。实现于 agent/errors.py。

可恢复异常

SkillExecutionError
工具执行失败 → LLM 可尝试其他方法
ProviderError
429 / 500 / 502 / 503 → 指数退避重试 3 次
PlanError
规划失败 → 回退到单步 Plan
ToolError
通用工具异常 → LLM 收到结构化错误

不可恢复异常

SkillNotFoundError
技能未注册 → 致命，阻止启动
SkillPermissionError
Persona 无权该技能 → 拒绝执行

safe_tool_call() 包装器：try → 执行工具 → 成功返回原值；except → 构造 ToolError → 返回结构化 JSON {"error":..., "code":..., "_tool_error": true}。LLM 收到结构化错误后尝试替代方案。
