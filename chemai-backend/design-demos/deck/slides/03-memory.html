§ 09 · 记忆管理

三层记忆：工作→情景→档案

消息组装顺序：[学生档案 SystemMsg] → [情景记忆 SystemMsg] → [历史对话] → [当前输入]。实现于 agent/memory.py — MemoryStack 类。

层次存储位置容量生命周期用途
工作记忆
Working Memory		内存滑动窗口最近 20 条单次请求内当前对话即时上下文
情景记忆
Episodic Memory		内存字典无硬上限单次请求内关键事件（诊断结果、考试记录）
学生档案
Student Profile		数据库查询每生一份跨请求持久姓名、障碍类型、练习完成数

持久化机制

LangGraph Checkpointer → SQLite，服务重启不丢对话。AsyncSqliteStore 提供跨会话键值存储（学生诊断历史 ×5、教师偏好）。

上下文裁剪衔接

每次 Agent 调用前自动裁剪。触发：>30 条 → 保留最近 6 + 关键词命中 → LLM 摘要。结果写回 Checkpointer。

对话重置

清空 Checkpoint 消息列表（写入空数组），清除内存中的对话元数据缓存。如同新建对话。
