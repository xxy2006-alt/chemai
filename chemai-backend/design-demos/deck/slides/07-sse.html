§ 13 · SSE 事件协议

11 种事件将 Agent 思考过程实时投射到前端

LangGraphSSEAdapterV2 将 astream_events 映射为结构化 SSE 事件。实现于 agent/langgraph_sse_v2.py。

核心事件类型

  • phase — 状态切换：thinking → executing → planning → reply → awaiting_approval
  • tool_call / tool_result — 工具调用开始/结束（含 name、args、success）
  • text — LLM 流式文本，逐 token 推送
  • component / navigate — 内联面板渲染 + 页面跳转
  • populate / action — 数据填充 + 前端行为
  • exam_images / error / done — 图片 + 异常 + 结束

文本去重算法

LLM 有时逐字复述工具输出 → 去重维护 4 个状态：
① 上一条工具输出文本（对比基准）
② LLM 新回复前缀累积（前缀匹配）
③ 去重决策锁（判断后不再重复判断）
④ 工具完整性标记（guidance/step 键 → 跳过）

重叠 > 70% → 判定为回显 → 跳过
