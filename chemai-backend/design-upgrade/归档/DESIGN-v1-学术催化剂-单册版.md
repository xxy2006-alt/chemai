## 第二段：跨页面可复用组件模式（源自 38 号前端页面设计规格）

> 从 14 个页面中扫描出的跨页面重复组件。每个模式 = 基础结构 + 变体 + 使用条件。新页面遇到同类需求，MUST 复用以下模式，禁止另起炉灶。

### P-01 对话气泡 `chat-bubble`

| 变体 | 视觉 | 使用条件 |
|------|------|---------|
| `chat-bubble-ai` | Teal 浅底（#e0f2f1 一类浅青）左对齐，圆角 12px | 所有 AI 消息（教师端主面板 / 学生端 AI 助教） |
| `chat-bubble-user` | 白底浅灰边框，右对齐，圆角 12px | 所有用户消息 |

出现页面：AI Agent 对话主面板（教师）、AI 助教对话（学生）。

### P-02 状态标签/徽章 `status-badge`（基础类 + 颜色修饰类）

基础类定义圆角胶囊（9999px）、浅底深字；修饰类只改颜色，不重复结构：

| 场景 | 修饰类 | 颜色 |
|------|--------|------|
| 审核徽章 | `badge-passed` / `badge-warning` / `badge-blocked` | 绿 #e7f2ec/#2c6e49 · 黄 #fdf3e3/#b45309 · 红 #fbeae7/#b43c28 |
| 障碍类型标签 | `badge-concept`（紫）/ `badge-reading`（蓝）/ `badge-expression`（青） | 平行区分，无等级关系 |
| OCR 状态徽章 | `badge-done` / `badge-processing` / `badge-failed` | 绿 / 黄 / 红 |
| 考试状态标签 | 草稿 / 已发布 / 进行中 / 已完成 | 中性色系 |

出现页面：考试工作台（审核徽章）、学生管理（障碍标签）、OCR 批改（状态徽章）、考试列表（状态标签）。

### P-03 顶部标题栏 `top-bar`

移动端 56px 高，Oxford Blue（#002147）背景：左侧返回箭头 + 居中/左对齐标题 + 右侧操作图标。学生端全部 6 页、家长端 2 页共用。

### P-04 底部 Tab 导航 `bottom-tabbar`

移动端固定底部，56px 高，当前激活项 Oxford Blue 高亮：
- 学生端 4 Tab：AI 助教 / 练习 / 错题 / 我的
- 家长端 3 Tab：概览 / 学习报告 / 消息

### P-05 侧边栏 `sidebar`

教师端左侧固定 232px：品牌标识、新建对话按钮、历史会话列表、底部快捷导航；平板折叠为仅图标。

### P-06 统计/KPI 卡片 `kpi-card`

4 列网格数字卡片（大号数字 + 标签），加载态数字闪烁占位。出现页面：班级学情面板（考试数/关注学生/平均分/及格率）、学生管理统计栏、学生个人报告（完成数/正确率/打卡天数）。

### P-07 学生卡片 + 详情抽屉 `student-card` + `detail-drawer`

卡片网格（分页 20 条/页）→ 点击滑出右侧 480px 详情抽屉（个人画像/成绩趋势/活动时间线）。出现页面：学生管理；学情面板关注学生卡片点击跳转并自动打开抽屉。

### P-08 弹窗 `modal`

三层叠加：半透明遮罩（阻断背景操作）→ 白色卡片（圆角 16px）→ 底部按钮区（确认/取消，右对齐）；大内容弹窗可滚动。移动端报告类弹窗用底部滑出式。

### P-09 通知提示 `toast`

右上角浮出轻量提示，Oxford Blue 底白字，3 秒自动消失，不阻断操作。

### P-10 骨架屏 `skeleton`

灰色占位条/占位卡片/闪烁数字，模拟真实内容形状——加载态 MUST 使用。

### P-11 空状态 `empty-state`

半透明烧杯图标 + 灰色引导文字，告诉用户"可以做什么"而非"暂无数据"（如"请先创建一次考试"）。

### P-12 上传区域 `upload-zone`

拖拽虚线框（约 500×300px），悬停高亮边框，支持 JPG/PNG/BMP/WEBP/PDF，单批最多 10 张，单文件 ≤10MB，上传后进度条 + 结果表格。出现页面：答题卡 OCR 上传区（内嵌于批改页）、考试工作台 OCR 导入 Tab。

### P-13 进度条 `progress-bar`

0-100% 填充动画，用于 OCR 处理进度、文件上传。

### P-14 题目卡片 `question-card`

题目内容 + 审核徽章（passed/warning/blocked）+ RAG 来源标识 + 陷阱提示 + 操作按钮（编辑/删除/加入考试/加入题库）。出现页面：考试工作台出题结果、题库管理网格。

### P-15 审核标记 `audit-mark`

四维安全审核结果标记：全部通过（绿底四 ✓）/ 部分警告（黄底对应维度 ⚠）/ 阻断（红底对应维度 ✗，题目不出现在学生端）。

### P-16 考试卡片 `exam-card`

考试卡片列表 + 状态标签（草稿/已发布/进行中/已完成）+ 操作菜单（编辑/发布/导出/删除）。出现页面：考试工作台 Tab4。

### P-17 数据表格 `data-table`

OCR 识别结果表格：学号/姓名/答案摘要/状态徽章/重试按钮（仅失败行显示）。

### P-18 搜索筛选栏 `search-filter-bar`

搜索输入框 + 筛选 chip（多选，选中自动触发筛选，实时搜索）：
- 学生管理：姓名搜索 + 班级/障碍类型筛选
- 历史真题库：地区/年份树形浏览 + 关键词搜索
- 题库管理：文件夹树 + 关键词搜索

### P-19 分页控件 `pagination`

列表底部页码，当前页高亮，含首页/中间页/末页状态。出现页面：学生卡片网格（每页 20 条）、练习任务列表。

### P-20 手风琴折叠列表 `accordion-list`

点击标题展开/折叠，同一时间仅一个展开：
- 错题本卡片：展开态含题目 + 错误答案（红）+ 正确答案（绿）+ 障碍标签 + 解析 + "生成变式题"/"已掌握"按钮
- 障碍诊断分组学生列表：按障碍类型分组折叠，学生行含置信度进度条 + 薄弱知识点标签

## 第三段：设计理念的可执行约束规则（源自 35 号设计系统）

> 每条规则 = MUST / MUST NOT / SHOULD + 正例反例。AI 生成界面时逐条自查，违反任意 MUST 即视为不合格输出。

### Color Rules

- **R-C1 · 主操作按钮** MUST 使用 Oxford Blue `#002147` 实心背景 + 白色文字。
  正例：出题工作台"生成题目"按钮、考试列表"创建考试"按钮。
  反例：Teal 背景的"生成题目"按钮——Teal 是 AI 的声音，不是系统命令。
- **R-C2 · Teal `#0d7377` 专属于 AI 声音**：AI 对话气泡、AI 按钮（智能出题/AI 诊断）、AI 生成内容标记。NEVER 用于主操作按钮、导航、系统标题。
  正例：AI 助教对话气泡用 Teal 浅底；反例：侧边栏导航用 Teal 高亮。
- **R-C3 · 页面背景** MUST 为冷调 `#f7f9fc`；卡片/弹窗表面 MUST 为 `#ffffff`；侧边栏/分区底色 MUST 为浅灰面 `#f1f5f9`。
- **R-C4 · 文字层级**：正文 MUST `#0f172a`；次要说明/时间戳/标签 MUST `#475569`；占位符/禁用态 MUST `#94a3b8`。
- **R-C5 · 语义色**：错误/删除/阻断 MUST `#b43c28`；成功/通过/正确 MUST `#2c6e49`；链接 MUST `#2563eb`。
- **R-C6 · 语义状态呈现**（通过/警告/阻断）MUST 用「浅色背景 + 深色文字」标签式（#e7f2ec/#2c6e49、#fdf3e3/#b45309、#fbeae7/#b43c28）。NEVER 用纯色大面积填充传达状态。
  正例：审核徽章浅绿底深绿字；反例：整块红色背景卡片表示"错误"。
- **R-C7 · NEVER 自行发明新颜色**。色板之外的颜色一律不许出现；确需新增，先更新本文件第一段。

### Typography Rules

- **R-T1 · 化学式/方程式/代码/数字数据** MUST 使用 JetBrains Mono（等宽）——上下标必须对齐，`H₂SO₄` 的 ₂₄ 不偏移。NEVER 用非等宽字体渲染化学式。
- **R-T2 · 正文** MUST 使用系统字体栈（PingFang SC / Microsoft YaHei / Noto Sans SC）。SHOULD 不引入 Web 字体依赖（本地加载更快、渲染一致）。
- **R-T3 · 标题** SHOULD 使用系统无衬线加粗，与冷调现代风格一致。

### Chemistry Rules

- **R-H1 · 化学方程式渲染** MUST 使用 KaTeX + mhchem 扩展（`\ce{}` 语法）。示例：`\ce{CH4 + 2O2 -> CO2 + 2H2O}`。
- **R-H2 · 纯文本化学式** MUST 转换为上下标格式再展示（H2O → H₂O、SO4^2- → SO₄²⁻、Fe^3+ → Fe³⁺）。

### Radius & Shadow Rules

- **R-R1 · 圆角四档**：按钮 8px · 卡片 12px · 弹窗 16px · 标签胶囊 9999px。NEVER 混用其他圆角值。
- **R-R2 · 阴影三级**：1px / 4px / 12px 模糊半径，层级分明不喧宾夺主；卡片悬停轻微上浮 + 阴影加深。

### Layout Rules

- **R-L1 · 教师端侧边栏** MUST 固定 232px；平板（768-1023px）折叠为仅图标。
- **R-L2 · 移动端** MUST 按 430×900 视口设计，内容容器居中，模拟手机框架。
- **R-L3 · 详情抽屉** MUST 480px 右侧滑出，带遮罩层。
- **R-L4 · 移动端底部导航** MUST 56px 高，激活项 Oxford Blue。
- **R-L5 · 桌面端（教师）三栏**：侧边导航 + 主内容区 + AI 对话面板；信息密度高，表格为主。

### State Rules

- **R-S1 · 每个页面 MUST 覆盖三态**：加载态（骨架屏/闪烁数字）· 空态（烧杯图标 + 可操作的引导语）· 错误态（错误描述 + 重试按钮）。
  反例：加载中显示空白页、失败无重试入口。
- **R-S2 · 空态** MUST 给出下一步行动（如"暂无考试数据，请先完成一次考试"），NEVER 只写"暂无数据"。

### Interaction Rules

- **R-I1 · 发送消息后** 输入框 MUST 清空并禁用（防重复发送），快捷芯片隐藏，Agent 状态栏切换。
- **R-I2 · 审批类操作** MUST 出现确认/取消卡片（黄色边框、浅黄背景），教师确认后继续。
- **R-I3 · 通知/Toast** MUST 右上浮出、3 秒自动消失、不阻断操作。
- **R-I4 · 跨页面跳转** MUST 走 Agent 桥接协议（SSE navigate/populate/action → 前端桥接存储 → 目标页自动配置状态），不靠 URL 裸传业务参数。

## 第四段：整体约束与已知缺口

### 整体约束

1. AI 生成或修改任何 ChemAI 界面代码前，**必须先读本文件**。
2. 参数冲突时以第一段数据块为准；数据块未覆盖的，查本段缺口表；**禁止自行发明设计参数**。
3. 修改设计系统（35 号文档）时，MUST 同步更新本文件第一段。
4. 14 个页面不是 14 个孤岛：跨页面数据传递一律走桥接协议（学情面板 → 学生管理自动开抽屉；Agent → 出题工作台预填参数；练习 → 错题本增量同步）。
5. 页面口径：教师 7 页（6 外显 + 1 内联——出题工作台为考试工作台 Tab1 / Agent 内联面板 exam-workbench）· 学生 6 页 · 家长 2 页 = 14 个页面条目。

### 已知缺口（源文档未定义 → 默认处理方式）

| 编号 | 缺口 | 默认处理方式 |
|------|------|-------------|
| GAP-01 | 间距尺度体系未定义（35 号无 8/16/24/40 类间距表） | 暂用 8 / 16 / 24 / 40 四档；卡片内边距 ≥16px，区块间 ≥24px，使用前需产品方确认 |
| GAP-02 | 渐变按钮色值未定义（铜蓝→靛蓝→甲基绿无具体色值） | 暂用主色系渐变（#0d7377 → #2563eb → #16a34a），或直接用 Oxford Blue 主按钮替代 |
| GAP-03 | 字号/字重/行高未定义（只有字体族） | 标题 20-28px 加粗；正文 14-16px、行高 1.5-1.75；代码 12-13px |
| GAP-04 | 深色模式未支持 | 不实现深色模式；界面一律浅色冷调 |
| GAP-05 | 平板端学生端/家长端未定义（35 号只定义了教师端平板折叠） | 复用移动端布局 + 适当加宽内边距 |
| GAP-06 | 通知渠道（邮件/短信/LMS 集成）展示样式未定义 | 仅实现站内 Toast + 家长端消息 Tab；外部渠道后续迭代 |
| GAP-07 | 多主题切换未支持（仅标准色域） | 不支持多主题；禁止为"换肤"预留半套变量 |
