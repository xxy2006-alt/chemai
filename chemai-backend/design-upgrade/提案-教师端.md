## 二、对 Linear 文件的违例声明（有意不遵守的规则）

| Linear 原规则 | 本融合的处理 |
|---|---|
| "Don't ship a light-mode marketing page" | 教师端就是浅色——该规则针对其营销站，工作台浅色由 inverse token 推导 |
| 薰衣草蓝用于 primary CTA | **不采纳**：主按钮归 Oxford Blue（Q2），薰衣草蓝降级为焦点/链接/选中 |
| "不引入第二彩色" | 实际有三个彩色（蓝/薰衣草青），靠岗位表隔离；Oxford Blue 近中性，实际观感仍是"单彩" |
| display 600、拒绝 700+ | 采纳（教师端无 900 大字需求，KPI 数字用 mono 600） |

## 三、v1 规则与缺口修订

- **GAP-01 间距**：正式采纳 4 基数八档，废除暂行的 8/16/24/40。
- **GAP-02 渐变按钮**：**建议废弃**——Linear 明令 no gradients，纯色 Oxford Blue 即可。
- **GAP-03 字号**：按上方 scale 定稿。
- **R-C7 色板**：新增 `accent-interactive` 三值 + `dark_panel` 区 + `teal-bright`；链接色并入薰衣草蓝。
- **新增 R-C8（提案）**：薰衣草蓝 NEVER 用于大面积填充、AI 元素、主按钮；深色嵌板内同理用 focus 色。
- **新增 R-L6（提案）**：AI 嵌板是深色区，其内部组件一律用 `dark_panel` token，NEVER 混用浅色 token。
