## 二、关键映射（v1 组件 → Spotify 化）

| v1 组件 | 学生端新形态 |
|---|---|
| P-01 AI 气泡 | AI = `surface` 底白字 + 1px `rgba(45,212,191,0.35)` 描边左对齐；用户 = `accent` 亮青实底胶囊 + `on-accent` 深字右对齐 |
| P-03 顶部栏 | 取消 Oxford Blue 实底顶栏 → 融入 canvas，仅返回箭头 + 700 标题（深色沉浸） |
| P-04 Tab 栏 | `#181818` 底 + 激活 Teal 亮变体 |
| P-06 KPI 卡 | `surface` 卡 + 900 大数字（display 字体）+ `text-secondary` 标签 |
| P-10/11 骨架/空态 | 骨架 = `#1f1f1f` 闪烁；空态烧杯图标 + 可操作引导语（R-S2 不变） |
| KaTeX | 化学式继承白字 + JetBrains Mono；错误/正确高亮用语义色 |

## 三、对 Spotify 文件的违例声明

| Spotify 原规则 | 本融合的处理 |
|---|---|
| Spotify Green 是唯一强调色 | 槽位让给 Teal 亮变体 `#2dd4bf`（Q3 定案），绿色只以 success 语义色存在 |
| "Don't add additional brand colors" | 多了 success/info 两个功能色——做题场景的对错反馈不可省 |
| 紧凑行高/10-24px 字域 | 做题正文放宽到 16px/1.6——学习场景可读性优先 |
| 大写按钮 | CJK 不适用，以 700 字重替代（见 typography.note） |
| "album art 提供所有颜色" | 类比映射：题目卡的知识点徽章/掌握度进度条承担"内容色彩" |
