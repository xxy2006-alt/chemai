# ChemAI 教师端 UI 改造 · 设计素材生成提示词文档

**版本**: v1.0
**用途**: 交给设计 agent（Midjourney / DALL·E / 即梦 / 豆包 / Recraft / Stable Diffusion 等）生成教师端新 UI 所需全部图片素材。
**配套**: 本文件与《ChemAI 教师端现代化改造方案》（方向 A · 现代学术蓝）同步生效；生成结果归入 `frontend/src/assets/`。

---

## 0. 使用说明

1. **品牌基线**（第 2 节）是所有提示词的公共前缀，每个素材提示词都要带上，保证整套素材风格统一。
2. 每个素材提供 **中文提示词**（适合即梦/豆包等国内模型）和 **英文提示词**（适合 Midjourney/DALL·E 等国外模型），二选一直接粘贴。
3. 所有素材**必须透明背景**（PNG，2x 尺寸导出，即实际像素 ×2），logo 额外要一份 SVG。
4. 生成后按第 5 节命名规范放入 `frontend/src/assets/` 对应子目录；我这边在素材就位前会用**诚实占位**（灰色块 + 标注），素材到位即替换。
5. 数量与优先级：**P0 = Phase 1 样板页（对话工作台 + 班级学情）必需**；P1 = Phase 2 其余页面；P2 = 可选加分项。

## 2. 品牌基线（所有提示词的公共前缀）

**中文品牌块**（粘贴到每个中文提示词开头）：

```
现代教育科技品牌「智辅化学 ChemAI」的视觉素材。风格：现代学术蓝、简洁、专业但不冰冷、扁平矢量、大圆角、克制的现代感。
主色牛津蓝 #002147（深藏蓝，用于主视觉与文字）、辅助色学术青 #0d7377（青绿，用于 AI/科技元素点缀）、表面白色 #ffffff 与浅灰 #f8fafc、成功绿 #2c6e49。
主题元素：化学元素符号、分子结构、烧瓶试管、原子轨道，与"AI 智能"（对话气泡、神经网络、电路）结合。
禁忌：不要米黄纸张质感、不要衬线字体、不要实验室笔记本方格、不要 3D 拟真、不要照片拼贴、不要渐变紫。
```

**English brand block**（粘贴到每个英文提示词开头）：

```
Modern edtech brand asset for "ChemAI", a high-school chemistry AI teaching assistant.
Style: modern academic blue, clean, professional but warm, flat vector, large rounded corners, restrained contemporary design.
Primary color Oxford Blue #002147 (deep navy), secondary teal #0d7377 (for AI/tech accents), surfaces white #ffffff and light gray #f8fafc, success green #2c6e49.
Motifs: chemical element symbols, molecular structures, flasks and test tubes, atomic orbitals, combined with AI hints (chat bubbles, subtle circuit or neural lines).
Forbidden: beige paper texture, serif typography, lab-notebook grid, photorealistic 3D, photo collage, purple gradients.
```

## 3. 逐素材提示词

### 3.1 主 Logo（P0）

**设计要点**：图形标需在 16px favicon 下依然可辨；建议图形标 + 中文文字标（"智辅化学"）两版；图形标可独立使用于头像位/窗口图标。

**中文提示词**：
```
[品牌基线] 设计一个化学教育 AI 产品的 Logo。
图形：一个简洁的扁平矢量标志，将"化学元素符号 H"与"AI 对话气泡"融合，或采用"烧瓶/试管内嵌分子结构"的抽象图形；需体现化学（元素/分子）与智能（对话/AI）双属性。
风格：几何极简、单色或双色（牛津蓝 #002147 与学术青 #0d7377 两色搭配），线条圆润，无描边锯齿，16px 缩放下仍清晰。
输出：① 纯图形标（透明底）；② 图形 + 中文"智辅化学"横排文字标（透明底，比例约 2:1）。
```

**English prompt**:
```
[Brand block] Design a logo for a chemistry education AI product.
Mark: a clean flat vector emblem merging the chemical element symbol "H" with an AI chat bubble, OR an abstract flask/test-tube shape containing a molecular structure; must convey both chemistry (elements/molecules) and intelligence (conversation/AI).
Style: geometric minimal, one or two colors (Oxford Blue #002147 + teal #0d7377), rounded strokes, crisp at 16px favicon size.
Output: (a) standalone mark, transparent background; (b) mark + horizontal Chinese wordmark "智辅化学" (transparent, ~2:1 ratio).
```

### 3.2 favicon（P0）

用 Logo 图形标直接导出 64×64 透明 PNG 即可，无需单独生成（若设计 agent 能同时出多尺寸则一并要 16/32/48/64）。

### 3.3 AI 助手头像（P0）

**中文提示词**：
```
[品牌基线] 设计一个圆形 AI 化学助教头像：扁平矢量，一个友好的"分子/烧瓶"拟人形象，带微笑表情与 AI 对话气泡元素，学术青 #0d7377 为主色、牛津蓝 #002147 点缀，纯色背景（白色或主色），居中构图，圆内完整、不留出血。
```

**English prompt**:
```
[Brand block] Design a circular AI chemistry tutor avatar: flat vector, a friendly personified molecule or flask character with a smile and a small AI chat-bubble motif, teal #0d7377 dominant with Oxford Blue #002147 accents, solid white or navy background, centered composition fully inside the circle.
```

### 3.4 教师默认头像（P0）

**中文提示词**：
```
[品牌基线] 生成一张教师用户默认头像：扁平矢量，中性风格的成年教师剪影（男女皆可，无性别倾向），圆角矩形或圆形构图，牛津蓝 #002147 背景 + 白色人物剪影，简洁、专业、亲和，无文字。
```

**English prompt**:
```
[Brand block] A default teacher avatar: flat vector, gender-neutral adult teacher silhouette, circular composition, Oxford Blue #002147 background with white silhouette, simple, professional and approachable, no text.
```

## 5. 交付与验收规范

**命名与存放**（生成后请按此放置，我直接引用）：

```
frontend/src/assets/
  logo/logo-mark.png（512px）、logo-mark.svg、logo-horizontal.png（2:1）
  favicon/favicon.png（64px）
  avatars/ai-tutor.png、teacher-default.png
  illustrations/empty-chat.png、empty-class.png、empty-students.png
  illustrations/login-hero.png（P1）
  illustrations/empty-bank.png、empty-diagnosis.png、empty-grading.png、empty-search.png（P1）
  illustrations/mascot.png（P2）、error-state.png（P2）
```

**验收清单**：
- [ ] 透明背景（PNG），无白底方框
- [ ] 2x 导出（实际使用尺寸 ×2），放大不糊
- [ ] 无衬线字体元素（Logo 文字标除外，可用中文黑体）
- [ ] 色板符合品牌基线（牛津蓝 #002147 / 学术青 #0d7377 为主）
- [ ] 无米黄纸感、无实验室方格、无紫渐变
- [ ] 同一批素材风格一致（同一模型同一 seed 族生成效果更稳）
- [ ] Logo 16px 缩放下可辨认（favicon 达标）

**替换机制**：素材就位前，样板页使用诚实占位（灰色块 + 素材名标注）；你按批交付后我逐张替换并截图确认。
