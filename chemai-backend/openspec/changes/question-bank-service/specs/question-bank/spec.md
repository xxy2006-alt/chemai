## Purpose

统一 AI 生成题库（QuestionSet）的持久化与检索入口，消除多入口行为漂移，并保证保存的题目可被搜索命中。

## ADDED Requirements

### Requirement: 保存题目时按正文去重
系统 SHALL 在把题目加入题库时按题目正文（content）去重——内容相同的题目不得重复插入，SHALL 复用已有题目记录并建立新的题库关联。

#### Scenario: 两次保存相同内容的题目
- **WHEN** 向同一题库保存一道题目，随后再次保存内容完全相同的题目
- **THEN** 系统只保留一条题目记录与一条题库关联，第二次保存被跳过，不重复插入、不重复关联

#### Scenario: 保存不同内容的题目
- **WHEN** 向题库保存内容不同的多道题目
- **THEN** 系统为每道题创建独立的题目记录，题库内不产生任何合并

### Requirement: 系统题库删除守卫
系统 SHALL 拒绝删除标记为系统预设（is_system=True）的题库，任何入口都不得绕过该守卫。

#### Scenario: 尝试删除系统题库
- **WHEN** 通过 HTTP 接口或 Agent 工具请求删除一个 is_system 为真的题库
- **THEN** 删除被拒绝，系统返回失败信息，题库及其关联保持不变

#### Scenario: 删除用户自定义题库
- **WHEN** 请求删除一个 is_system 为假的题库
- **THEN** 删除成功，题库及其题目关联被移除

### Requirement: 保存即同步，保存后可被搜索命中
系统 SHALL 在保存题目到题库时同步更新向量索引与历史真题库，使保存后的题目可通过搜索入口（带或不带关键词）被检索到。

#### Scenario: 保存后带关键词搜索
- **WHEN** 用户保存若干题目后，使用与题目知识点相关的关键词搜索
- **THEN** 搜索结果中包含刚保存的题目

#### Scenario: 保存后不带关键词搜索
- **WHEN** 用户保存若干题目后，仅按地区/年份/难度条件搜索，不提供关键词
- **THEN** 搜索结果中包含刚保存的题目

### Requirement: 所有写入入口行为一致
系统 SHALL 让所有题库写入入口（HTTP API 与 Agent 工具）经由同一服务层，并表现出相同的去重、删除守卫与同步行为。

#### Scenario: 经不同入口保存相同题目
- **WHEN** 通过 HTTP 导入接口保存一道题，再通过 Agent 工具保存内容相同的另一道题
- **THEN** 两道入口都不会产生重复题目记录，且都触发向量索引与历史真题库同步

### Requirement: 搜索联合返回历史真题与 AI 题库
搜索入口 SHALL 联合返回历史真题（真题库）与 AI 生成题库中的命中结果，不得遗漏任一来源。

#### Scenario: 搜索同时命中两类题目
- **WHEN** 执行一次搜索，其关键词同时匹配历史真题与 AI 生成题库中的题目
- **THEN** 返回结果同时包含两类来源的题目，并标注各自来源
