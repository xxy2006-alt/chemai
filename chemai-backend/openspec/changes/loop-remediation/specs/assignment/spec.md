## MODIFIED Requirements（assignment）

### Requirement: 同步布置幂等
同步路径的重复布置调用（同一教师、同一目标、同一来源要点）SHALL 幂等——不产生重复练习记录与重复通知。

#### Scenario: Agent 工具双触发
- **WHEN** 同一布置请求被连续触发两次
- **THEN** 第二次返回已存在的练习记录，不新建重复卷

### Requirement: 自适应来源支持主观题型
自适应生成的题型 SHALL 不限于选择题，按知识点配置可含主观题，并经判卷中心语义判定管线判定。

#### Scenario: 布置含主观题的自适应练习
- **WHEN** 配置的自适应练习包含计算/填空题
- **THEN** 学生作答后主观题进入待判定管线并最终落定判定
