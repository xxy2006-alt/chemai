09 · Vibe Coding

提示词配方

prompt.txt · 四步配方
01问框架　项目用什么框架?网页 / H5 / 小程序?
　　　「我用 React 19 做个人作品集网站」
02选组件库　按框架选,团队用哪个用哪个
　　　「组件库我选 Ant Design」
03对组件名　不知道叫什么?反问 AI,让它报名字
　　　「删除确认在 antd 里叫什么组件?」
04写代码　用库里的组件,沿用主题,只写业务
　　　「用 Modal 做删除确认,确认后调接口」
05要迭代　不满意就改,一句话一版
　　　「弹窗加淡入动画,文案再明确点」
　　　(公司项目:技术栈和组件库是团队定的,直接沿用)
