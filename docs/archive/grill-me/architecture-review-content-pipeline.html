1. formula_result — Discarded Gold

Strong
import_single_paper.py app/services/ocr_service.py

Problem

doc_analysis 返回两个结果：words_result（纯文本）和 formula_result（LaTeX 格式的化学式，如 V _ { 2 } O _ { 5 }、Fe ^ { 3 + }）。但导入脚本 只取了 words_result 的纯文本，丢弃了 formula_result。

结果：OCR 把 SO₃ 当纯文本输出成乱码，而 formula_result 里的 S O _ { 3 } 本可以转成 KaTeX 渲染。LLM 收到的已经是污染的文本，无法还原正确的化学式。

Solution

导入时合并 formula_result。利用每个 formula 的 form_location（位置坐标）和 words_result 里每个 word 的 location，按位置对齐——OCR 文本中对应位置的乱码片段，替换为 \ce{...} 或 \frac{...}{...} 包裹的 LaTeX。

替换后的文本传给 LLM → LLM 输出中保留 LaTeX 标记 → 前端 KaTeX 正确渲染。

2. LLM Output Is a Wall of Text

Strong
import_single_paper.py frontend/pages/exam-v2.html

Problem

LLM 输出的 content 是单行纯文本——没有段落分隔、没有换行、没有 LaTeX 标记。用户看到的是一片连续文字："硫酸是一种重要的基本化工产品。接触法制硫酸..." 里面图(a)图(b)的引用悬在空中，公式像乱码。

真正的高考题排版是：题目题干 → 选项分行 → 子问题编号。但现在全糊在一起。

Solution

LLM 输出结构化 HTML/Markdown。在 LLM 提示词里要求用 Markdown 格式：content 字段支持双换行分段，子问题用 **(1)** 编号。前端 renderChem 函数在渲染前做 Markdown→HTML 转换，并调用 KaTeX 渲染 \ce{} 和 $...$ 块。

另外，题目带"如图所示"/"如图(a)"的，前端在文字上方展示对应的 page_image。

3. renderChem Only Renders \ce{}

Worth exploring
frontend/js/agent.js:952-959 frontend/pages/exam-v2.html:624

Problem

window.renderChemistry() 只处理 \ce{...}，不支持行内数学 $...$ 和分数 \frac{}{}。OCR 输出的公式可能用这些格式，但前端无法渲染。而且 exam-v2.html 的 renderChem 只是透传到 renderChemistry，没有做 Markdown→HTML 的转换。

Solution

增强 renderChem 为三阶段管道：Markdown 分段 → KaTeX 公式渲染 → HTML 输出。先按双换行分段加 <p>，再识别 $...$ 和 \ce{...} 调用 KaTeX，最后输出。

Top Recommendation

三个问题的根因是一条链上的三个断裂点。按顺序修：

1

合并 formula_result（Candidate 1）

在导入脚本中，用 formula 的位置坐标替换 words_result 中对应位置的乱码文本为 LaTeX 标记。这是唯一的正确输入源。约 30 行改动。

2

LLM 输出 Markdown（Candidate 2）

改 LLM 提示词，要求用双换行分段、子问题编号。content 保留 LaTeX 标记。约 5 行改动。

3

增强 renderChem（Candidate 3）

加上 Markdown 分段 + 完整 KaTeX 支持（$...$ 和 \ce{}）。约 20 行改动。
