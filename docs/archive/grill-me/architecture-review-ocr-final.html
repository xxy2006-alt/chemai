化学试卷的特殊难点

🧪 化学方程式

H₂SO₄、CH₃COOOH
Fe³⁺ + e⁻ → Fe²⁺
OCR 容易把下标/上标/
箭头读成乱码

🏗️ 有机结构式

苯环、碳骨架、
空间结构图
纯图片，不是文字

📊 实验装置/曲线图

滴定曲线、反应机理、
流程图、催化剂循环
图片为主，文字为辅

结论：纯文字 OCR 解决不了化学试卷。"图片必须在题目中作为一等公民存在。"

三个核心改动

推荐 1. Qwen-VL-OCR 替代百度全家桶

已验证：Markdown + Unicode 上下标 + LaTeX 数学全对。无日限额（阿里百炼按量付费）。

删除: ocr_service.py 中所有百度调用、paper_cut_client.py、grading_client.py、baidu_auth.py

优先级 2 2. Markdown Splitter — 按题号拆分

Qwen-VL-OCR 输出是连续的 Markdown。利用其自然结构（`## N.` 标题、`【答案】` 标记）正则拆分为独立题目。每道题目保留 Markdown 格式。

优先级 2 3. 图片提取 + 内联渲染

PyMuPDF 从 PDF 提取嵌入图片到 figures/ 目录。Qwen-VL-OCR 文本中保留 `![figure](figures/img_001.png)` 引用。前端 Markdown 渲染器解析 img 标签，正确显示结构式/曲线图。

优先级 3 4. 前端 Markdown 渲染增强

题目详情页支持完整 Markdown 渲染（marked.js）+ KaTeX 公式 + 内嵌图片。替代当前的 renderChem 纯文本方案。
