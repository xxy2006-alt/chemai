### P-01 对话气泡（chat-bubble）
- **用于**：T1、S1、P2 浮动 AI 面板
- **结构**：消息流容器内，AI 气泡与用户气泡交替排列
- **契约**：
  - AI 气泡：Teal 浅色底（S1 明确为 `#e0f2f1`）、左对齐、圆角（S1 为 12px）
  - 用户气泡：白底 + 浅灰边框、右对齐
  - 气泡内容支持 KaTeX 化学式渲染（见 P-18）
- **状态**：流式输出中（SSE 逐字渲染）；T1 额外有工具调用卡片（带实时计时器）与审批卡片（黄边框米黄底，确认/取消）

### P-02 快捷芯片（quick-chips）
- **用于**：T1（6 个）、S1（5 个，横向可滚动）、P2（5 个预设提示词）
- **契约**：预设提示语按钮，横向排列；位于输入区上方；点击即发送对应提示语
- **状态**：默认可见 → 发送首条消息后隐藏（T1 明确）
- **文案来源**：静态配置（非 API）

### P-03 会话侧边栏（conversation-sidebar）
- **用于**：T1（固定 240px）、S1（抽屉 280px，左侧滑出 + 遮罩点击关闭）
- **契约**：品牌/用户信息区 → 新建对话按钮 → 历史会话列表（最新在顶）→ 底部快捷导航/退出
- **交互**：点击切换会话；长按删除（T1）；数据 = 会话列表 API + 客户端本地缓存
- **状态**：默认展开 / 折叠仅图标（T1 桌面端）；加载时骨架屏灰色占位条

### P-04 移动端标题栏（mobile-header）
- **用于**：S1–S6、P1、P2（全部移动端页面）
- **契约**：高 56px、Oxford Blue 底、白色文字；左槽（返回箭头/汉堡菜单）+ 中槽（页面标题，可带右侧进度如"X/Y"）+ 右槽（功能图标，最多 1–2 个）

### P-05 底部 TabBar（bottom-tabbar）
- **用于**：S1–S5（学生端 4 Tab：AI 助教/练习/错题/我的）
- **契约**：高 56px；当前激活 Tab 为 Oxford Blue，其余灰色；跨页面导航（独立 HTML 页面间跳转，非 SPA）

### P-06 统计数字卡（stat-card）
- **用于**：T3（4 KPI）、T4（4 项）、S3（3 项）、S4（3 项）、S5（3 列）、P2（2×2）
- **契约**：网格均分排列；大号数字（Oxford Blue；S2 得分等展示级数字用 Cormorant Garamond 衬线）+ 下方小字标签（text_secondary）
- **状态**：加载中 = 数字闪烁占位（全页面统一）；无数据时按 P-14 空态处理

### P-07 状态徽章（status-badge）
- **用于**：T2（审核徽章 passed/warning/blocked；考试状态 草稿/已发布/进行中/已完成）、T6（OCR 状态 done/processing/failed）、T7
- **契约**：统一「浅底 + 深字」小标签（遵循语义色规范）；配色映射：
  - passed/done/已完成 → 绿系 | warning/processing/进行中 → 黄系 | blocked/failed → 红系 | 草稿/已发布 → 中性灰/蓝
- **文案规则**：blocked 项必须同时从学生端消失（不仅是视觉标记）

### P-08 进度条（progress-bar）
- **用于**：T5（置信度条，高 6px，灰底 Oxford Blue 填充）、T6/T7（上传进度 0–100% 填充动画）、S2（任务进度）、P2（知识点掌握进度）
- **契约**：灰色底轨 + 主色填充；百分比或级别标注；T5 置信度三档：≥0.8 高置信 / 0.7–0.8 标"需关注" / <0.7 标"建议复核"

### P-09 弹窗与抽屉（overlay）
- **用于**：T4（480px 右侧详情抽屉滑入 + 遮罩；添加学生/调班弹窗）、S5（底部滑出弹窗：学习报告/学习计划）、P2（AI 迷你面板，半透明覆盖）、T1（审批卡片为对话流内变体）
- **契约**：三层结构 = 遮罩 → 内容卡片 → 底部右对齐按钮区（确认/取消）；大内容加滚动区；遮罩点击关闭（抽屉/底部弹窗）
- **方向变体**：居中弹窗（教师端表单）/ 右滑抽屉（详情）/ 底部滑出（移动端报告）

### P-10 Tab 导航（tab-nav）
- **用于**：T2（4 Tab，下划线指示激活）、S2（2 Tab 带计数"待完成(N)"）、P2（3 Tab，底部蓝色下划线）
- **契约**：顶部水平排列；激活态 = 下划线 + 高亮色；切换 = 显示/隐藏对应 div（MPA，非路由）；带计数变体在文案后附 `(N)`

### P-11 手风琴卡片（accordion-card）
- **用于**：T5（分组学生列表）、S3（错题卡片）
- **契约**：折叠态 = 摘要 + 标签；展开态 = 完整内容 + 操作按钮；**同一时间只允许一个展开**（点击标题切换）
- S3 展开态固定结构：题目 + 错误答案（红）+ 正确答案（绿）+ 障碍类型标签 + 解析 + 「生成变式题」「已掌握」按钮

### P-12 上传区域（upload-zone）
- **用于**：T6（500×300px 虚线框）、T7（同 T6）、T4（批量导入）、T1（文件按钮）、S1（拍照上传）
- **契约**：虚线框 + 云上传图标 + 提示文字 + 「选择文件」按钮；支持点击与拖拽
- **状态**：默认（虚线）→ 拖拽悬停（边框高亮）→ 上传中（进度条）
- **限制**（T6/T7）：JPG/PNG/BMP/WEBP/PDF；单文件 ≤10MB；单批 ≤10 张；上传后 5 秒轮询任务状态

### P-13 登录表单（login-form）
- **用于**：S6（学号/手机号 + 密码）、P1（手机号 + 6 位绑定码）
- **契约**：Logo 区（烧瓶图形 + "ChemAI 智辅化学" Oxford Blue 24px + 副标题）→ 表单区（带图标输入框 + 全宽登录按钮，高 48px Oxford Blue）→ 底部辅助链接 + 版本号
- **状态**：登录中（按钮"登录中..."禁用）；失败（输入框红框 + 抖动 + 下方红色提示）
- **特殊**：P1 绑定码输入框 `maxlength=6` 仅数字，附浅蓝说明卡片

### P-14 页面三态（page-states）—— 全局强制模式
- **用于**：全部 15 页，任何数据驱动区块
- **契约**：
  - 加载态：骨架屏（卡片/条目灰色占位）或数字闪烁（统计类）或三点弹跳（36 号全局）
  - 空态：图标 + 引导性文案（必须告知下一步动作，如"暂无考试数据，请先完成一次考试"）
  - 错误态：错误描述 + 重试入口（横幅"连接中断，点击重试"/ Toast / 行内重试按钮）
- **降级**：T3 有第四态「演示模式」——API 不可用时用内置静态示例 + 模拟数据标识

### P-15 数据选择器（data-selector）

## 第四段：整体约束与已知缺口

### 4.1 整体约束（跨全部页面生效）

1. **架构形态**：MPA 多页应用，非 SPA。Tab 切换 = div 显示/隐藏（T2 明确）；学生端 6 个独立 HTML 由底部 TabBar 串联。
2. **零构建**：Tailwind CDN 类名内联表达全部样式；Vite 仅做多页面打包，不产生 CSS 编译步骤。
3. **数据流协议**：Agent 对话走 SSE 流式渲染；跨页跳转走「Agent 导航桥接」——工具返回 `_route` → SSE 适配器发 `navigate/populate/action` → 桥接存储 → 目标页加载时读取并自配置（如自动打开学生抽屉、加载指定考试）。
4. **页面间数据传递固定路径**：学情面板→学生管理（学生 ID）；Agent→出题工作台（知识点/难度/题型）；Agent→诊断面板（班级 ID+考试 ID）；练习→错题本（新增错题）。
5. **答案持久化**：练习页切换题目不得丢失已选答案；提交失败保留答案。
6. **降级策略**：图表类页面 API 不可用时进入演示模式（静态示例 + 明确标识）。
7. **渲染优先级**：化学式渲染正确性 > 动效 > 装饰。任何装饰元素与可读性冲突时，装饰让位。
8. **家长端特殊原则**：40–55 岁用户，低认知负荷、移动优先、不制造焦虑（文案避免负面排行/对比）。
