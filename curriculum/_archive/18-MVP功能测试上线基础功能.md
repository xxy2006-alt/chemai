### 1.2 错误注入测试

`chemical_balance` 的错误注入测试方法：

```python
# 构造 5 个已知有错的化学方程式
test_cases = [
    ("2H2 + O2 = 2H2O", True),      # 正确
    ("H2 + O2 = H2O", False),         # 系数不对
    ("Fe + O2 = Fe3O4", False),       # 产物错了
    ("Na + H2O = NaOH + H2↑", False), # 未配平
    ("2KMnO4 = K2MnO4 + MnO2 + O2↑", True), # 正确（加热条件标注）
]
for eq, expected in test_cases:
    result = audit_chemical_equation(eq)
    assert result.is_valid == expected
```

全部 5 个用例通过，0 个 false negative。

### 7. MVP 上线的定义

ChemAI 没有"生产服务器"。上线的定义是：
1. `python -m uvicorn app.main:app` 无错误启动，HTTP 200
2. 种子教师通过局域网 `http://192.168.x.x:8000` 访问
3. 8 个核心功能全部可用（每个功能教师都实际使用过）
4. 无已知 P0/P1 blocking bug

**当前状态**：已上线。种子教师已使用约 2 个月（2 月初→3 月底）。
