# 10 · 评测集构建

## 不是用公开 benchmark，是自己构造的

ChemAI 的评测集在 `evals/` 目录下，不是一个文件，是一套测试体系。

### 评测文件清单

```
evals/
├── test_langgraph_agent.py     # Agent 路由 + 工具调用 + 护栏测试
├── agent_eval_golden.yaml      # 20 个 Golden 数据集场景
├── golden_routing.yaml         # 路由专项测试
└── run_evals.py                # 运行入口
```

### 第一层：LLM 化学知识评测

10 道题，覆盖高考化学六大板块。直接从 2020-2024 高考真题中选，不是从公开题库中随便挑。

**测试脚本**：`evals/test_langgraph_agent.py --golden`

**10 道题**（手工挑选，确保每个板块 ≥1 题）：

| 题号 | 板块 | 知识点 | 来自真题 |
|------|------|--------|---------|
| 1 | 离子反应 | 判断离子共存 | 2020 全国卷 T1 改编 |
| 2 | 氧化还原 | 配平 KMnO4 + HCl | 2020 全国卷 |
| 3 | 元素化合物 | Fe、Al 性质比较 | 2020 全国卷 T5 改编 |
| 4 | 化学反应速率 | 速率计算 | 2020 全国卷 T10 改编 |
| 5 | 化学平衡 | 勒夏特列原理判断 | 2020 全国卷 T10 改编 |
| 6 | 电化学 | 原电池/电解池判断 | 2020 全国卷 T6 改编 |
| 7 | 有机化学 | 官能团性质判断 | 2020 全国卷 T12 改编 |
| 8 | 物质结构 | 电子排布式书写 | 2020 全国卷 T11 改编 |
| 9 | 化学实验 | 气体制备装置选择 | 2021 湖南卷 |
| 10 | 计算 | 化学平衡常数计算 | 2020 全国卷 T10 改编 |

**评分标准**：每题 0-2 分
- 2 分：方程式系数/条件/产物/结构全对
- 1 分：有细节遗漏（如漏写反应条件、单位错误）
- 0 分：关键错误（配平错、产物错、概念混淆）

**实际运行结果**（2026-05-15）：

```
Golden 数据集: 10/10 通过
  平均得分: 2.0/2.0
  化学式正确率: 100%
  反应条件正确率: 100%
```

### 第二层：Agent 路由评测

20 条真实用户输入，验证每条输入是否路由到正确的子专家。

**测试文件**：`evals/agent_eval_golden.yaml`

**数据格式**（YAML）：
```yaml
scenarios:
  - name: "出题意图-简单"
    input: "我要出题"
    expected_agent: "exam_expert"
    expected_tool: "show_exam_workbench"
  - name: "讲解意图"
    input: "讲解氧化还原反应"
    expected_agent: "tutor_expert"
  - name: "联网搜"
    input: "上网搜索 2026 高考改革"
    expected_agent: "search_expert"
    expected_tool: "web_search"
```

20 条场景覆盖：
- 6 个路由到不同子专家的 happy path
- 2 个空知识点/信息不足的反问场景
- 2 个出题 → 保存 → 跳转的完整 workflow
- 2 个护栏测试（去重/approval）
- 3 个 Gateway 关键词边界测试
- 5 个模棱两可的输入（验证协调器兜底）

**实际运行结果**（v3 Multi-Agent）：
```
20/20 场景全部通过
  路由准确率: 100%
  工具调用准确率: 100%
  护栏触发率: 2/2 (dedup + approval)
```

v2（LangGraph ReAct）的时候只有 12/20 通过（60%）。提升来自 Gateway 关键词预路由。

### 评测不在 CI 里，是手动跑的

因为 ChemAI 没有 CI/CD。评测由开发者在本地执行：
```bash
python evals/run_evals.py            # 全部
python evals/test_langgraph_agent.py --golden     # 只跑 Golden
python evals/test_langgraph_agent.py --regression # 只跑回归
```

### 评测输出作为"已知缺口"

`agent_eval_golden.yaml` 的 `known_gaps` 部分记录了当前已知但未修复的问题：

```yaml
known_gaps:
  - id: search-exam-bank-not-reading-sqlite
    severity: high
    desc: search_exam_bank 只读 JSON 文件，Agent 保存到题库的题目无法被搜索到
  - id: llm-skip-approval
    severity: medium
    desc: LLM 有概率不调 request_approval，即使明确要求确认
  - id: route-not-persisted
    severity: low
    desc: _route 数据通过 SSE 传递，前端未打开时丢失
```

这些 gap 不是"没测到"——是测到了但优先级不够高，放在下次迭代修。
